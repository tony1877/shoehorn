# shoehorn 0.2.0

## Images

Qwen3.8-27B now reads images: give a model its vision encoder (llama.cpp's mmproj GGUF) and send images in chat
messages. Details: [docs/VISION.md](../VISION.md).

- OpenAI `image_url` / `input_image` parts and Anthropic `image` parts, as base64 data URLs or http(s) URLs (the server
  fetches them: 20 MB, 20 s).
- The encoder runs on the GPU on 24 GB+ cards when it fits (0.03 s for a 640x400 image) and on the CPU otherwise
  (about 2 s on a Ryzen 9800X3D).
- Prompt reuse knows about images: a follow-up turn about the same image does not encode it again, and a different
  image never reuses the old one's state.
- Models page: a Vision button per model; downloading a GGUF repository selects its `mmproj-*.gguf`, and adding or
  packing a model from the download sets it.
- `shoehorn vision` answers one prompt about images from the command line. With the base alone it matches
  `llama-mtmd-cli`'s output word for word.
- dsh: the `read_image` tool, plus images dropped into the web chat.

## Smaller GPUs

- 8 GB profile: a 2-bit base (iq2_xxs + q4_K residual, 6.9 GB VRAM, KLD 0.0093 against Q8). The Models page offers it
  and warns when the pack has no imatrix.

## Server

- Repetition guard: a generation stuck repeating itself stops before a partial tool call is executed.
- Answer caps hold in assembled and streamed responses. The cap is checked every 256 bytes instead of re-parsing on
  every token.
- `shoehorn` with no arguments lists its commands.

## Packages

- New: a Windows zip (`shoehorn-0.2.0-windows-x86_64-cuda.zip`). It needs only the NVIDIA driver (580+) and includes
  cuBLAS and the VC++ runtime.
- Linux, as before: CUDA and ROCm tarballs, `.deb` and `.rpm`. They need the NVIDIA driver 570+ or ROCm 7; see
  [docs/linux.md](../linux.md).

## Checked

- Windows zip, unpacked to a fresh folder and run with a PATH without CUDA or Visual Studio, on the RTX 5080 with orca
  27B (Q4_K residual): the vision smoke test and the live policy checks pass. A 293-token prompt decoded at 31.6 tok/s.
- Linux CUDA tarball under WSL on the same GPU: `shoehorn vision` reads the test invoice correctly.
- `.deb` installed on Ubuntu 24.04 and `.rpm` on Rocky Linux 9 (containers, CPU fallback): both start and report 0.2.0.
- The ROCm tarball and packages were built but not run on an AMD GPU (none available).
